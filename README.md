Task 4 - Amazon Prime Dataset Logistic Regression Classification

Objective

To build a binary classification model using Logistic Regression on the Amazon Prime dataset and evaluate its performance.

Tools Used

- Google Colab
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

Steps Performed

1. Imported dataset
2. Cleaned and preprocessed data
3. Handled missing values
4. Encoded categorical features
5. Split data into training and testing sets
6. Standardized features
7. Trained Logistic Regression model
8. Made predictions on test data
9. Evaluated model using accuracy, confusion matrix, precision, and recall
10. Saved trained model

Dataset

Amazon Prime Movies and TV Shows Dataset from Kaggle
